Overview
--------
This project demonstrates a complete workflow for image and video processing using Python, OpenCV, and NumPy. It covers multiple core computer vision tasks, including edge detection, image compression, segmentation, frame extraction, video sampling, geometric transformations, frame differencing, spatial filtering, H.264 video compression, and bitrate-aware stream generation.

The implementation is organized to solve 10 assignment problems in a structured and reproducible manner. It can run on a built-in synthetic road-scene demo video or on a user-provided video input.

Objectives
----------
- Implement core image processing techniques using OpenCV
- Analyze image quality metrics such as MSE and PSNR
- Perform object/background segmentation and edge detection
- Extract and process frames from video data
- Compare image and video compression strategies
- Apply geometric transformations and filtering operations
- Generate compressed video variants for quality and bitrate evaluation

Project Structure
-----------------
The repository contains the following key components:

- Raushan_Kumar_IVP_Final_Code.py
  Main Python script containing all assignment implementations.

- RoadTraffic_Synthetic_Demo.mp4
  Synthetic road-scene demonstration video generated by the script.

- output_images/
  Output images for all image-processing tasks.

- extracted_frames/
  Frames extracted at regular intervals from the input video.

- processed_videos/
  Variants of processed videos for sampling, filtering, and compression tasks.

- metrics/
  JSON and CSV files summarizing computed metrics and results.

- execution_stdout.txt
  Standard output log generated during execution.

- execution_stderr.txt
  Error/output log generated during execution.

Requirements
------------
The following Python packages are required:

- Python 3.9 or newer
- OpenCV
- NumPy

Install dependencies:

    pip install opencv-python numpy

Optional:

- FFmpeg (required for H.264 compression and bitrate ladder experiments)

Make sure ffmpeg is available on your PATH if you want to generate H.264 streams and bitrate-based outputs.

Execution
---------
Run the script from the project directory:

    python Raushan_Kumar_IVP_Final_Code.py

This will create a synthetic demo video and process it automatically.

To use your own video:

    python Raushan_Kumar_IVP_Final_Code.py path/to/your_video.mp4

To save outputs to a custom folder:

    python Raushan_Kumar_IVP_Final_Code.py path/to/your_video.mp4 --output custom_output_dir

Included Tasks
--------------
The solution includes the following implemented problems:

1. Edge detection using Sobel and Canny filters
2. Image compression comparison using PNG and JPEG formats
3. Image segmentation using Otsu, adaptive thresholding, region growing, and watershed
4. Frame extraction at fixed intervals
5. Video sampling at different temporal rates
6. Geometric transformations: translation, rotation, and scaling
7. Frame differencing and change detection
8. Spatial filtering with median, Gaussian, and bilateral filters
9. Video compression using H.264 at different CRF values
10. Bitrate-based streaming evaluation for multiple target bitrates

Outputs Generated
-----------------
Each task produces output artifacts in the project folders. Examples include:

- Filtered and edge-detected image outputs
- Compressed JPEG and PNG variants
- Segmentation masks and watershed results
- Extracted frames from the source video
- Downsampled and processed video files
- Numerical metrics in JSON and CSV formats

Metrics and Evaluation
----------------------
The script computes and stores quantitative evaluation results including:

- MSE and PSNR values for compression analysis
- Number of saved frames in extraction tasks
- Percentage of changed pixels for differencing tasks
- Mean PSNR values for filtered outputs
- Compression and bitrate summaries

These results are saved in:

- metrics/metrics_comparison.json
- metrics/summary.csv

Important Notes

- The metrics in this repository correspond to the included synthetic demonstration video unless otherwise modified.
